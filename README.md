# Puzzled
Contains the game Puzzled along with the commits.  

The game idea came from one of the first things I made in my CS class.  The project I made was a game with a 4 word phrase in which the player of the game had to unscramble the words.  It was pretty simple just that one game and it was very finicy especially since you had to put in one word a time for each of the 4 words.  


In this game there are 4 games even though the third one is just a combination of the first three that I added for extra fluff.  

1.   The first game is a word scramble game that probably took me the majority of the time spent on the project maybe a hour and a half or longer with the majority of the time being spent on the scrambling feature
2.   The second game the number puzzle a logic game with number patterns was built off the same outline as word scramble with similar variables and success checking.
3.   All like the second game word puzzle is a logic game but with words that was also built off word scrambles outline.
4.   The challenge is the fourth game mode which really just calls the other 3 and tracks overall score.

The project overall was like 2.5 hours of coding and a hour of debugging mainly with games 1 and 4.  The anyways this is my first real project because folktale didn't require a lot of this extra stuff so I'm still learning java and web design through css so this is just a quicker simple learning game.
